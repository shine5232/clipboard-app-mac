# 剪贴板助手 - macOS 版

一个功能强大的多选剪贴板管理工具,支持自动监听、批量粘贴和多种输出模式。

## 功能特性

### 🎯 核心功能

- **自动监听剪贴板**: 每次复制内容时自动添加到列表
- **批量粘贴**: 支持三种输出模式
  - 逗号拼接: 将所有内容用逗号连接
  - 顺序输出: 按复制顺序依次粘贴
  - 倒序输出: 按复制倒序依次粘贴
- **胶囊模式**: 窗口可缩小为边缘胶囊,节省屏幕空间
- **全局快捷键**: 随时随地快速访问

### 🎨 界面特性

- **现代化 UI**: 简洁美观的界面设计
- **主题切换**: 支持日间/暗夜模式
- **多种配色**: 魅力蓝、天空蓝、青草绿、樱花粉
- **流畅动画**: 胶囊模式的飞入飞出动画

### ⌨️ 快捷键

- `Cmd+Shift+C`: 显示/隐藏主窗口
- `Cmd+Option+V`: 批量粘贴剪贴板内容
- `Cmd+Shift+Q`: 退出程序

## 安装方法

### 方式一: 从源码运行

1. 克隆或下载本项目
2. 安装依赖:
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序:
   ```bash
   python main.py
   ```

### 方式二: 打包成 .app 应用

1. 安装依赖
2. 运行打包脚本:
   ```bash
   chmod +x build.sh
   ./build.sh
   ```
3. 将 `dist/剪贴板助手.app` 拖到应用程序文件夹

## 使用说明

### 首次运行

首次运行时需要授予以下权限:

1. **辅助功能权限**:
   - 打开 系统偏好设置 > 安全性与隐私 > 隐私 > 辅助功能
   - 添加 Python 或终端到允许列表

### 基本使用

1. **添加内容**: 正常使用 `Cmd+C` 复制,内容会自动添加到列表
2. **查看内容**: 点击托盘图标或按 `Cmd+Shift+C` 显示窗口
3. **批量粘贴**: 按 `Cmd+Option+V` 粘贴所有内容
4. **删除内容**: 鼠标悬停在项目上,点击删除按钮

### 胶囊模式

将窗口拖拽到屏幕边缘(左/右/上/下)会自动进入胶囊模式:
- 胶囊显示当前剪贴板项目数量
- 鼠标悬停或双击胶囊可恢复主窗口
- 再次双击标题栏×按钮切换回正常模式

### 输出模式

在设置中可以选择三种输出模式:

1. **逗号拼接** (默认):
   ```
   复制: "Apple", "Banana", "Cherry"
   粘贴: Apple,Banana,Cherry
   ```

2. **顺序输出**:
   ```
   复制: "Apple", "Banana", "Cherry"
   粘贴: Apple (回车) Banana (回车) Cherry
   ```

3. **倒序输出**:
   ```
   复制: "Apple", "Banana", "Cherry"
   粘贴: Cherry (回车) Banana (回车) Apple
   ```

## 系统要求

- macOS 10.13 或更高版本
- Python 3.8 或更高版本

## 依赖库

- PyQt5: GUI 框架
- pynput: 全局快捷键和键盘模拟
- pyperclip: 剪贴板操作
- pyobjc: macOS 原生 API 访问

## 故障排除

### 快捷键不工作

确保已授予"辅助功能"权限。

### 粘贴功能不工作

1. 检查目标应用是否支持粘贴
2. 确保剪贴板有内容
3. 尝试重启应用

### 应用无法启动

查看详细错误信息:
```bash
./剪贴板助手.app/Contents/MacOS/剪贴板助手
```

## 与 Windows 版本的区别

此版本是从 Windows 版本迁移而来,主要区别:

- 使用 Command 键替代 Ctrl 键
- 使用 macOS 原生 API (AppKit, Quartz)
- 单实例检测使用文件锁替代 Mutex
- 快捷键适配 macOS 习惯
